高玥集团 OA 全员办公原型 · 2026-10-18

【入口与保存】
公开演示：https://gaoyue-ceo-workbench.acus-ny-9168.chatgpt.site/
本地可用 Edge / Chrome 打开 index.html。单个 HTML 包含全部界面与逻辑。
预填项目、人员、金额、授权额度、日期均为演示。右上切换身份用于体验不同人员权限。
数据仅存当前浏览器；底部可导出、导入 JSON 备份。升级不主动重置已有记录。
两个窗口同时修改会检测过期表单，防止旧数据覆盖新内容。不同设备的数据不互通。

【人员与权限】
CEO：全公司工作、方向与模板、关键决策、共同验收和授权。
总经理：在“管理负责人”下选择“演示总经理”；全公司工作视角，可制定日常模板；敏感人事、合同、财务仍需独立授权。
主管：安排直属员工的模板、临时工作、日计划和班次，确认成果，协调缺勤与跨项目支持。
员工：在“员工”下选择“演示仓储员工”等人员。没有项目的员工也可办理人事、资产与每日工作。
人事行政：演示顾经理；维护全员档案、岗位、任职和人事行政流程，职能可拆分移交。
财务：演示钱经理、何财务；审批与实际办理分开，规则管理权由CEO明确授予。
负责人及员工只查看负责或参与的项目，私人待办不进入公司统计。

【日常模板到实际成果】
1. CEO/总经理进入“组织与资源 → 任务体系 → 日常模板”，填写内容、完成要求、频率、截止规则，保存后发布。
2. 直属主管在“主管安排”分派模板到人，填写生效范围与优先级。
3. “日历与排班”配置固定工作日或轮班，采用所在地时区；跨夜仍算一班，夏令时重复时刻明确选择先后。
4. 员工打开“每日工作”，按安排生成清单；也可选择日期点击生成。重复生成不新增重复事项，休息日不生成。
5. 员工提交实际成果、资料名称/说明/网址，可添加评论。
6. 主管在“提交确认”按员工与工作日逐项或批量确认，允许单项退回补充。
7. “及时性与成果”记录首次提交、补交、当时截止和确认时刻；没有质量评分或人员排名。
模板修改为草稿时原发布版本继续生效；新版本不覆盖历史实例。调整未提交实例需明确选择影响项并说明原因。
工作生成与提醒仅在页面内运行，关闭页面后没有后台任务。

【非日常、支持与缺勤】
主管可安排不关联项目的部门临时事项。项目日计划引用原任务，不重复创建或统计。
跨项目支持由项目负责人提需求，员工直属主管统一安排；只显示必要摘要，不开放原项目详情。
请假、出差或调休批准后，在“调配与缺勤”查看影响清单，支持单项和多项同类处置：
代办：本人接受后推进获授权事项，原责任人和实际成果作者分别保留。
延期：保留原期限和原因；项目期限调整须审批后生效。
本次免执行：日常仅免本周期，非日常仅免当天安排；不把整个任务标为完成，未来安排仍保留。

【项目与验收】
项目大阶段为“0–1基础建设”或“基本运作与创新”，与生命周期分开。
普通任务由项目负责人检查。阶段及重点成果由CEO与指定另一位负责人分别确认。
任一方退回后，新版成果重新双确认；历史旧验收不补造第二位签名。
负责人检查补充异常、下一步与待决策事项，系统已有进度自动汇总。

【行政与财务】
保留请假、出差、调休、入职、转岗、离职、工作交接，以及设备台账、领用、借还、维修、采购。
人事、行政、财务按职能授权，支持当前兼任、未来拆分。
财务办公包括报销、借款备用金、付款、预算申请与调整。主管确认需求、财务核对，超额度、超预算或特殊事项升级。
审批链提交时保存快照。禁止自己审批自己，离职审批人需明确重派；退回/撤回后在原记录重提。
审批通过不代表已办理。财务另行登记付款、归还、核销或预算应用，填写唯一流水标识，防止重复和超额。
不同币种分开处理，不连接银行。存在财务办公记录的项目使用归档保留追溯。

【通知与个人工作台】
通知按人员、部门或岗位发布。重要通知每版确认，普通通知无需逐人确认。
直属主管跟进未确认员工，提醒仅在页面展示，不发送外部消息。
成员工作台保留档案、合同、出勤、岗位、日历和私人待办；旧考核记录保留，新任务不生成质量评分。
管理工具保留风险、指标历史、模板、代理和周承诺；新任务也可登记周承诺，复杂度只用于协商。
附件仅展示名称、说明和链接，不实际上传文件。

【源码与开发】
index.html 为可运行单页，core.js 为构建提取的逻辑副本。修改模块后在源码包根目录依次运行：
node ceo-workbench/build-oa.mjs
node ceo-workbench/build-governance.mjs
node ceo-workbench/build-operations.mjs
node ceo-workbench/build-oa-upgrade.mjs
完整验证：node ceo-workbench/verify-all.mjs
浏览器测试使用隔离数据、本地HTTP、Playwright和Edge。测试文件内运行时路径需按开发电脑调整。
当前没有真实账号、服务端权限隔离、跨设备同步、真实支付或外部通知；正式多人系统另行建设。
